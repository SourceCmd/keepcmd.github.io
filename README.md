# keepcmd.com

The Keep Cmd website, served by GitHub Pages at https://keepcmd.com.

- `index.html`, `support.html`: the site.
- `install.sh`: a copy of the installer, so `curl -fsSL https://keepcmd.com/install.sh | sh` works. It's written by the release script and fetches everything from https://get.keepcmd.com.
